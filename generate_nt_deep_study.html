Generate New Testament Deep Study Data

Select a New Testament book. This utility downloads the BSB display data, converts the English text and Strong's mappings into the Kingdom Bible Utility Deep Study format, validates the conversion, and downloads the finished book JSON file.

Bulk generation validates all 27 books sequentially, then enables one ZIP download. Keep this page open while it runs. No download starts automatically. If a book fails or you cancel, no partial ZIP is offered. The ZIP stores uncompressed JSON files (up to 64 MiB of JSON), so it may take some disk space.

Download nt-deep-study.zip

After downloading, right-click the ZIP and choose Extract All. Expect 27 book JSON files and a validation-report.txt. Extract to a separate review folder; do not copy files into data/deep-study yet.

Batch validation checks all 27 books in memory. It does not download JSON files or change the application or its Deep Study datasets.
