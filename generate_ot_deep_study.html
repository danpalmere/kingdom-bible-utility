Generate Old Testament Deep Study Data

Select an Old Testament book. This utility downloads the BSB display data, converts the English text and Strong's mappings into the Kingdom Bible Utility Deep Study format, validates the conversion, and downloads the finished book JSON file.

Choose Validate Selected Book to check source data without downloading, or Generate to validate and download one book JSON file. Each chapter is fetched sequentially. No partial file is downloaded when a chapter fails or you cancel.

Batch validation checks all 39 Old Testament books (929 chapters), shows progress, continues after a book fails, and supports cancellation. It never downloads files or changes Bible datasets. Keep the page open while it runs.

Jonah uses the BSB source ID JON, but downloads as JNH.json to match this application. Do not upload generated datasets to the live repository yet. No Hebrew or Aramaic lexicon is installed yet, so lexical definitions will be a later step.
